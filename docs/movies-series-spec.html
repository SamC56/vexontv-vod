Adding Movies & Series to VexonTV

VexonTV is built for live TV only. It throws away movie and series entries while it loads a playlist. This plan keeps those entries, gives them two new sections in the side menu, and adds the player controls on-demand video needs: seeking, resume and an up-next screen.

What the code does today

js/api.js:4

MOVIE_OR_SERIES drops any M3U line whose URL contains /movie/ or /series/. Xtream only calls get_live_*, and Stalker only calls get_all_channels.

js/player.js

AVPlay can open, play, pause and stop. It has no seek, no duration and no position reporting. oncurrentplaytime is only used to detect that playback started.

js/store.js

One flat state.channels[listId] array and nothing else. Only lists, favorites and recents go to localStorage. Channels are fetched again on every launch.

js/app.js · js/tv.js

Navigation is built from named focus zones with onEdge hand-offs. New screens just define new zones. Only the Red, CH± and Play/Pause keys are registered.

  • Live TV stays the same. Its categories and channel lists only ever contain live streams, so nothing changes for people who just watch channels.
  • Movies and Series are separate catalogs. They are fetched the first time you open them, not at boot. VOD catalogs on Xtream panels often have 20,000–80,000 entries.
  • No build step and no new dependencies. The new code uses the same Preact + htm screens and the same focus engine, follows the same Prettier rules, and comes with tests in the existing three suites.

How it looks

These are drawn at 1920×1080 using VexonTV's own colors, side menu and focus ring. The posters are coloured placeholders; the real app shows the cover art from the panel.

Questions before we build

  1. Which source types do you actually use?If it's Xtream, Phase 1 starts there and the M3U guessing can be simpler.
  2. Is the poster grid right, or would you rather have rows?The alternative is the current list-row style with a preview panel on the right, which is closer to Live TV. Posters suit a film library better, but this is your call.
  3. What should the fork be called?A separate package id in config.xml lets it install next to VexonTV instead of replacing it.
  4. Should Recent and Favorites mix live and on-demand content, or keep them in separate tabs?The plan uses tabs on Favorites and one mixed Recent list.
